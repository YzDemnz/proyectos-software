# LUMEN · Biblioteca digital

Biblioteca con catálogo, búsqueda y administración de archivos PDF y EPUB.

Proyecto personal de Jesús Leonardo Martínez Rodrigues.

## Tecnologías

React · TypeScript · Vite · PostgreSQL

## Desarrollo

```powershell
npm ci
npm run dev
```

## Alcance

Autenticación y almacenamiento requieren backend propio. La red social ampliada sigue pendiente. No se incluyen libros, perfiles, correos ni archivos subidos.

## Distribución

Copia de fuentes para revisión técnica. Sin dependencias instaladas, credenciales, bases de usuario ni cachés. Se conservan las licencias incluidas y no se concede una licencia nueva sobre componentes de terceros.
