# Judicial Managment

Aplicación de gestión jurídica para expedientes, clientes, movimientos y colaboración por despacho.

Proyecto personal de Jesús Leonardo Martínez Rodrigues.

## Tecnologías

React · TypeScript · Vite · Electron · PostgreSQL

## Desarrollo

```powershell
npm ci
npm run typecheck
npm run dev
```

## Alcance

Incluye fuentes de web/escritorio y migraciones. Requiere configurar un backend propio. La publicación de código no reproduce datos de un despacho ni acredita pruebas nuevas de todos sus módulos.

## Distribución

Copia de fuentes para revisión técnica. Sin dependencias instaladas, credenciales, bases de usuario ni cachés. Se conservan las licencias incluidas y no se concede una licencia nueva sobre componentes de terceros.
