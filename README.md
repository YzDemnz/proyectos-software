# Proyectos de software

Portafolio técnico de Jesús Leonardo Martínez Rodríguez.

- [Judicial Managment](judicial-managment/README.md): Aplicación de gestión jurídica para expedientes, clientes, movimientos y colaboración por despacho.
- [MicroApp](microapp/README.md): Aplicación móvil y web para inventario, ventas, clientes y operación de pequeños negocios.
- [LUMEN · Biblioteca digital](lumen/README.md): Biblioteca con catálogo, búsqueda y administración de archivos PDF y EPUB.
- [Bastión / Night Shift](bastion/README.md): Prototipo cooperativo de supervivencia por oleadas para Roblox.
- [Discord Community Bot](discord-community-bot/README.md): Bot modular de tickets privados, moderación, archivos temporales y recordatorios de progresión.
- [Blender / Workbench · Herramientas de integración](blender-workbench/README.md): Scripts Python de construcción y comprobación para un flujo Blender y Workbench.
