# MicroApp

Aplicación móvil y web para inventario, ventas, clientes y operación de pequeños negocios.

Proyecto personal de Jesús Leonardo Martínez Rodrigues.

## Tecnologías

Expo · React Native · TypeScript · Express · SQLite

## Desarrollo

```powershell
npm ci
npm run typecheck
npm run backend
npm start
```

## Alcance

Backend local Node/Express con sql.js. Las integraciones de pagos y mensajería requieren configuración externa; no se publican secretos, ventas reales ni documentos legales en borrador.

## Distribución

Copia de fuentes para revisión técnica. Sin dependencias instaladas, credenciales, bases de usuario ni cachés. Se conservan las licencias incluidas y no se concede una licencia nueva sobre componentes de terceros.
