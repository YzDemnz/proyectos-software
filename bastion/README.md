# Bastión / Night Shift

Prototipo cooperativo de supervivencia por oleadas para Roblox.

Proyecto personal de Jesús Leonardo Martínez Rodrigues.

## Tecnologías

Luau · Rojo · Roblox Studio

## Desarrollo

```powershell
powershell -File tools/Build.ps1
powershell -File tools/Test.ps1
```

## Alcance

El servidor gestiona daño, cadencia, munición, compras y oleadas. Los datos duran la sesión; no hay DataStore. Las pruebas de consola no sustituyen validación de cámara, física y varios jugadores en Studio.

## Distribución

Copia de fuentes para revisión técnica. Sin dependencias instaladas, credenciales, bases de usuario ni cachés. Se conservan las licencias incluidas y no se concede una licencia nueva sobre componentes de terceros.
